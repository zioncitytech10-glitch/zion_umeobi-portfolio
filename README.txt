# Zion Umeobi — Portfolio Website

## Files
- `index.html` — complete responsive portfolio website with warm beige/brown styling and WhatsApp contact link
- `assets/zion-profile.png` — profile image used on the homepage

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `zion-umeobi-portfolio`.
2. Extract this ZIP file on your computer.
3. Upload `index.html` and the `assets` folder to the repository's root (not the ZIP file itself).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish your website.

The contact details and professional history in this first draft are based on information previously provided. Review the content and replace any detail that needs correction before publishing.
